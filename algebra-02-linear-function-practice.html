הסברים ודוגמאות בדף ההסבר.

רמה א׳: בסיס שאלות 1–9

  1. האם הקצב אחיד? אם כן, מהו?
    1. x: 0, 1, 2, 3 → y: 5, 8, 11, 14
    2. x: 0, 1, 2, 3 → y: 2, 4, 8, 16
    3. x: 0, 2, 4, 6 → y: 10, 7, 4, 1
    הצג פתרון

    א. אחיד, 3. ב. לא אחיד (2, 4, 8). ג. אחיד: y יורד ב־3 כש־x גדל ב־2, כלומר קצב \(-1.5\).

  2. חשבו את השיפוע בין הנקודות:
    1. \((1,2),(3,8)\)
    2. \((0,5),(5,0)\)
    3. \((-3,1),(1,3)\)
    4. \((2,4),(7,4)\)
    הצג פתרון

    א. 3 ב. −1 ג. \(\frac{1}{2}\) ד. 0

  3. רשמו את השיפוע ואת נקודת החיתוך עם ציר y:
    1. \(y=4x-1\)
    2. \(y=-x\)
    3. \(y=6\)
    4. \(y=\frac{1}{2}x+3\)
    הצג פתרון

    א. 4, \((0,-1)\) ב. −1, \((0,0)\) ג. 0, \((0,6)\) ד. \(\frac{1}{2}\), \((0,3)\)

  4. אילו מהישרים עולים, אילו יורדים ואילו אופקיים? \(y=2-5x\), \(y=0.1x\), \(y=-4\), \(y=x-10\).
    הצג פתרון

    עולים: \(y=0.1x\), \(y=x-10\). יורד: \(y=2-5x\). אופקי: \(y=-4\).

  5. כתבו את משוואת הישר ששיפועו 5 וחותך את ציר y ב־\((0,-2)\).
    הצג פתרון

    \(y=5x-2\).

  6. מצאו את משוואת הישר ששיפועו 2 ועובר דרך \((3,1)\).
    הצג פתרון

    \(1=6+b\Rightarrow b=-5\). \(y=2x-5\).

  7. האם הנקודה \((4,9)\) נמצאת על הישר \(y=2x+1\)? והנקודה \((-2,-3)\)?
    הצג פתרון

    \(2\cdot4+1=9\): כן. \(2(-2)+1=-3\): כן.

  8. מצאו את נקודות החיתוך עם הצירים של \(y=-3x+6\).
    הצג פתרון

    \((0,6)\) ו־\((2,0)\).

  9. בודדו את y ומצאו את השיפוע:
    1. \(3y=6x+9\)
    2. \(y-2x=5\)
    3. \(2x+y=7\)
    הצג פתרון

    א. \(y=2x+3\), 2 ב. \(y=2x+5\), 2 ג. \(y=-2x+7\), −2

רמה ב׳: ביסוס שאלות 10–17

  1. מצאו את משוואת הישר העובר דרך \((2,1)\) ו־\((5,10)\).
    הצג פתרון

    \(m=3\), \(1=6+b\Rightarrow b=-5\). \(y=3x-5\).

  2. מצאו את משוואת הישר העובר דרך \((-1,6)\) ו־\((3,-2)\).
    הצג פתרון

    \(m=\frac{-8}{4}=-2\), \(6=2+b\Rightarrow b=4\). \(y=-2x+4\).

  3. מצאו את משוואת הישר המקביל ל־\(y=4x-7\) ועובר דרך ראשית הצירים.
    הצג פתרון

    \(y=4x\).

  4. מצאו את משוואת הישר המקביל ל־\(y=-\frac{1}{2}x+1\) ועובר דרך \((4,3)\).
    הצג פתרון

    \(3=-2+b\Rightarrow b=5\). \(y=-\frac{1}{2}x+5\).

  5. הטבלה מתארת פונקציה קווית. מצאו את המשוואה והשלימו:
    x13510
    y410??
    הצג פתרון

    \(m=3\), \(b=1\): \(y=3x+1\). ב־5: 16, ב־10: 31.

  6. מונית: 11 ₪ בכניסה ו־3.5 ₪ לכל ק״מ.
    1. כתבו את המחיר \(y\) כפונקציה של מספר הקילומטרים \(x\).
    2. מה המחיר לנסיעה של 12 ק״מ?
    3. נסיעה עלתה 60 ₪. כמה ק״מ נסעו?
    הצג פתרון

    א. \(y=3.5x+11\) ב. 53 ₪ ג. \(3.5x=49\Rightarrow x=14\) ק״מ

  7. טמפרטורה של מים שמתחממים: בהתחלה 20°, ואחרי 5 דקות 45°, בקצב אחיד.
    1. מה קצב החימום?
    2. כתבו נוסחה.
    3. מתי המים יגיעו ל־100°?
    הצג פתרון

    א. 5° לדקה ב. \(T=5t+20\) ג. \(5t=80\Rightarrow t=16\) דקות

  8. מצאו את \(k\) כך שהנקודה \((k,7)\) תהיה על הישר \(y=3x-5\).
    הצג פתרון

    \(3k-5=7\Rightarrow k=4\).

רמה ג׳: אתגר שאלות 18–22

  1. האם הנקודות \((1,3)\), \((3,7)\) ו־\((6,13)\) נמצאות על ישר אחד?
    רמז

    השוו את השיפוע בין הנקודה הראשונה לשנייה לשיפוע בין השנייה לשלישית.

    הצג פתרון

    \(\frac{4}{2}=2\) ו־\(\frac{6}{3}=2\). אותו שיפוע ונקודה משותפת, לכן כן.

  2. הישר \(y=mx+3\) עובר דרך \((2,-1)\). מצאו את \(m\) ואת נקודת החיתוך עם ציר x.
    הצג פתרון

    \(-1=2m+3\Rightarrow m=-2\). \(-2x+3=0\Rightarrow(1.5,0)\).

  3. חברה א׳ גובה 50 ₪ לחודש ועוד 0.2 ₪ לדקה. חברה ב׳ גובה 0.4 ₪ לדקה בלי תשלום קבוע.
    1. כתבו נוסחה לכל חברה.
    2. אחרי כמה דקות המחיר שווה?
    3. מי משתלמת למי שמדבר 300 דקות בחודש?
    הצג פתרון

    א. \(y_A=0.2x+50\), \(y_B=0.4x\) ב. \(0.2x=50\Rightarrow x=250\) ג. א׳: 110 ₪, ב׳: 120 ₪. חברה א׳.

  4. הישר \(y=-x+6\) חותך את הצירים בנקודות A ו־B. מה שטח המשולש AOB, כש־O היא ראשית הצירים?
    הצג פתרון

    \(A(6,0)\), \(B(0,6)\). משולש ישר זווית עם ניצבים 6 ו־6: שטח \(18\).

  5. הנקודות \((0,2)\) ו־\((4,a)\) נמצאות על ישר שמקביל ל־\(y=1.5x-1\). מצאו את \(a\).
    הצג פתרון

    הישר: \(y=1.5x+2\). \(a=6+2=8\).
